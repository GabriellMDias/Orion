# ADR Instructions

- Consult the [decision index](README.md) and [authoring policy](authoring.md) before creating or changing an ADR.
- Start new proposals with the [template](template.md) and `proposed` status. Acceptance is distinct from implementation completion.
- Preserve accepted rationale, decisions, dates, and stable identifiers. Architectural changes require a new decision and explicit supersession, not rewritten history.
- Retain meaningful alternatives, negative consequences, constraints, and evidence. Do not invent evaluations to fill the template.
- Update current policy and reciprocal supersession references when an accepted architectural change requires them.
